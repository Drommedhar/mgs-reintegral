# Raven boss stage integration

`s15a` now links the recovered native Raven, container, and crow actors and its original constructor table. The original Integral Disc 2 binaries support reusing the `s15c` implementations: all 105 functions, totaling 11,220 instruction words, have the same instructions apart from code/data address relocation. The comparison covers 54 Raven, 37 container, and 14 crow functions. Referenced constants and switch tables also match after relocation, excluding explicitly identified unused string/table padding. [The evidence ledger](data/s15a_recovery.json) records the extents, overlay hash, relocated data, and all 30 constructor bindings.

The 352 Raven navigation and damage/update cases were executed again against the original **s15a** MIPS instructions. Their results equal the `s15c` reference fixtures; the unchanged recovered C passes the same cases in `mgs_valcan_navigation_test`. These tests intercept specified engine boundaries and do not establish complete rendering, sound, or fight behavior.

A Debug native run completed 1,800 VSyncs with the original `ea54.g` scenario's story211 fight branch. It created Raven and the container actor in mode1, rendered the warehouse with Snake and Raven's health bar, and accepted ordinary controller movement: 2,996 horizontal units across 24 movement ticks. The run exited cleanly. The [debugger fixture](../tests/fixtures/s15a_story211.cdb) sets an isolated story value and a known warehouse pose from the original later `sub_13CE`; it does not represent continuous campaign arrival. Gunfire was not reached from that safe pose, and neither boss defeat nor human playability has been verified. Logs and the inspected capture are `build/movie-audit/raven211.log` and `raven211.bmp`.

`patches/mgs-s15a.patch` adds only the `s15a` source selection and its constructor bindings. A fresh temporary Git index reproduced those changes exactly atop the 29 then-locked MGS patches. `config/stages.json` enables the stage. The selected resource variant matters: `s15a` contains the Raven body model used by the shared scenario; the later guard-revisit `s15c` variant does not contain that model.
