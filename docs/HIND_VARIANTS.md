# Remaining Hind tower variants

`s11h` now builds and runs as native C. Its 25 original constructor entries bind to recovered source; no MIPS constructor addresses remain. `s11b` is enabled by the subsequent [cinematic recovery](S11B_RECOVERY.md). The rappel stage `s11d` is still being recovered.

The shared Hind actor and blast effect in original `s11b` and `s11h` each match 11,648 original `s11g` instruction words after resolved code/data relocations. Referenced vector constants, 464 bytes of shared strings/switch tables, and five additional aiming switch entries also match after relocation. Each original variant independently reproduces all 720 flight/state fixture outputs used by the native Hind test. This establishes reuse of those routines; it does not establish that every actor in each stage is identical.

Two missing `s11h` actors were recovered from the supplied Disc 1 overlay: [PutHzd](../vendor/mgs/source/takabe/puthzd.c) registers collision walls/floors, optionally translates copied geometry, responds to its original messages, and unregisters its geometry on destruction. [InverseLight](../vendor/mgs/source/kojo/inverlt.c) projects eight textured light quads, triggers the original stun effects, and follows its original 15-tick lifetime. Native packets use their full pointer headers and both real primitive buffers. Missing required resources or allocation failures return a failed constructor.

The unchanged recovered geometry routines pass 448 independent original-MIPS cases: 192 collision translations include signed-short wrap, unchanged height fields, bounds, and surrounding memory; 256 light projections cover all eight scales and signed coordinate extremes. Together with the existing flight/ribbon cases, `mgs_hind_helpers_test` passes 1,456 cases. Source and test Aislop scans report zero findings.

The [runtime fixture](../tests/fixtures/s11h_story186.cdb) selects story 186 and the original story 185 pre-demo position `(5011,0,-3505)`, heading 1024. The authored script constructs PutHzd and Hind, the recovered aiming controller executes, and player control returns. Ordinary controller input moves Snake 2,888 units over 25 movement ticks; the Debug run completes 1,800 VSyncs cleanly. The screenshot shows Snake on the tower rooftop with the HIND health bar. The late combat controller breakpoint was not reached; this is stage-entry and movement evidence, not a completed boss fight or continuous campaign proof.

Exact addresses, relocations, constructor bindings, fixture provenance and runtime paths are in [the recovery ledger](data/s11h_recovery.json). Reproduction uses [the incremental patch](../patches/mgs-hind-variants.patch), pinned upstream sources, and user-supplied discs. Original assets and analysis databases remain untracked.
