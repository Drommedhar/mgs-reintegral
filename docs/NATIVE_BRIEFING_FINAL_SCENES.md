It covers the complete timed phases, scene state dispatch, transition conditions, three controlled helper outcomes, texture coordinates including byte wrap, and animation paths with synthetic coordinates. Comparisons check the modified packet payloads, actor state and visibility bytes, and ordered calls across controlled graphics/audio boundaries. Nested calls between these ten recovered routines execute normally in both implementations. External helpers have the same controlled behavior on both sides; these tests do not establish the behavior of those helpers or complete rendered playback.

The original actor has size `0xADC8` and uses 40-byte `POLY_FT4` packets. Native packets use a larger ordering-table tag. Recovered code therefore uses named actor members and typed packet pointers, including original accesses based at `work + 0x8000`, rather than preserving original byte offsets. GPU tag bytes are excluded from payload comparisons. Texture identifiers retain the original asset spelling and EUC-JP bytes. The three path tables use `DVECTOR` elements, preserving the original signed coordinates and indexing.

Public fixtures contain synthetic inputs and checksums of resulting state and call traces. Original executable/resource bytes and the local reference emulator remain private. All ten translation units compile with `-Wall -Wextra` without diagnostics. The scoped Aislop scan has seven nonfixable warnings for long recovered routines; test stubs retain two nonfixable parameter-count warnings because they match the original interfaces. No error or fixable warning remains.
